# PlanMySeat: Thane school admissions 2027-28

Free tracker for Nursery, Jr KG and Class 1 admissions (plus RTE 25%) in Thane West and Ghodbunder Road.
Will be live at **school.planmyseat.in**.

- `schools.csv`: the school list (form dates, age reference dates, official links).
- `index.html`, `style.css`, `app.js`: the page. Plain HTML, CSS and JavaScript.

Every date is checked against the school's official notice. Parents apply to schools directly;
PlanMySeat does not fill forms or collect documents.
